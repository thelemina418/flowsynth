# 04: Cadence

## Habits, classes, allowance

- A habit is a name plus one class. Only open classes can be chosen. Re-attuning is allowed, and earned class levels stay where they were earned.
- Credited flow time on a habit advances its class. Thresholds and grants are in `progression-map.md` and `mechanics-sketch.md`.
- Allowance counts placed modules per category, plus cables. Unplaced allowance is shown as count chips beside the board, e.g. `Oscillators 1`.

## Begin flow

```
Begin flow
Habit   [ Piano · Engineer ▾ ]   + New habit
Length  [25] [50] [90] [custom]
                                     [Begin]
```

## Flow screen

```
                     ⬡ board (resonance outlines pulse, beads run along cables)

ν 48 210            Engineer · Lv 2 ▕██████░░░▏ 1.1h / 1.5h
Shale  ▕███████░░░▏ 412 / 600 HP                 Ready · 3
                        31:04   [Pause] [End]
```

- `Ready · N` counts affordable faders plus unplaced allowance.
- The screen has no other controls and never prompts the player.
- Keep the focus apps from the old console (clock, Notes) available exactly as before. The console is ported, not redesigned.

## End of session

1. Honesty report, only if provisional time is owed.
2. Summary, with no paragraphs: `+48 210 ν · Engineer +50 min · Shale −412 HP`.
3. If at least 10 credited minutes: `Breather banked · 10 min`.
4. → Upgrade mode.

## Breather

- Upgrade mode shows `Take breather · 10 min` while one is banked.
- Taking it shows a calm screen: `Step away. The board is running. 9:41`. The board runs ×2 and Release wakes.
- It ends by itself. The next open shows `Breather complete · +31 400 ν · Shale −220 HP`.
- A banked breather survives a new flow session, and is replaced only when a newer one is banked.

## Goal line

There is always exactly one Goal, naming something visible: `Place a third oscillator` → `Conquer Shale` → `Conquer Basalt` → `Reach Flint` → … → `Prestige`. It is chosen by a fixed priority list per arc.

## Almanac

A planning view with **no effect on the board**. It merges the old Habit app, per-habit goals (now **Intentions**), Notes, the practice calendar and session history:
- per habit: total credited time, the last 7 and 30 days as a bar strip, and its class
- Intentions: e.g. `Piano · 40 / 60 min today`
- Notes and history, as before

## Encyclopedia

Ported and trimmed. Entries are Resonance, each pattern, Charge, Cables, Walls, Pressure, Classes, Breather and Prestige. Each appears when its concept first appears in play. One quiet unseen-dot, no tours.

## Acceptance

- A full loop works: Begin → 25 minutes → honesty report → summary → upgrade mode → breather → reopen → result → Begin.
- Before the first session, the screen shows exactly nine things.
