# Prestige keeps the board

Prestige resets only nous and global row levels. Placement, cells, cables, class levels and allowance all persist. Most incremental games reset the build. We do not, because rebuilding after a claim took about two-thirds of each later era (ADR-0086, `research/later-era-pacing-diagnosis.md`), and because lifetime victories already rule out re-fighting walls. Fresh play comes from arcs and outer walls instead.
