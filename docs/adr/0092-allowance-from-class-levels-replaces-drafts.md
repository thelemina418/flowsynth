# Allowance from class levels replaces drafts, rarity and module levels

Modules come from allowance. Each habit class (Engineer, Producer, Mixer, Roadie) grants allowance of its craft as it levels from credited flow time, and new types arrive at milestone levels. Drafts, rolls, rarity, merge tiers, scrap, the Forge and per-module levels are removed. Nous buys strength only through always-visible global rows. We chose this split so real hours buy options and nous buys strength, and so "Upgrade All" stops being the dominant way to play.
